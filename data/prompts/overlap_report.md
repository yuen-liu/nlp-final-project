## Headline

**All 11 Morgulis steer_train files reuse the 50 Cloud et al. eval prompts verbatim, in the same order.** Every prompt is an exact match (index i = index i). The 11 animal files differ only in the target label. Morgulis's `eval_finetune.py` also evaluates on these same prompts (`eval_finetune.py:163-169`, called with the same `--prompts-json` at `topic_job.sh:205`), so their steering vector is trained on the exact eval prompts. **If we train v_c on these files and score with `eval_animal.json`, training and eval sets are 100% identical.**

## Morgulis cat set under the decision-1 rule

Rule: start from `steer_train_cat_morgulis.json` and drop every training prompt flagged above (exact, normalized-exact, or near-duplicate) against ANY of the 50 eval questions. Eval uses all 50 Cloud questions.

**Result: 0 of 50 prompts survive.** 50 are flagged, all as exact matches, because Morgulis's cat file *is* the Cloud eval set. `steer_train_cat_morgulis.json` is kept as a reference (the Morgulis-50 reference v_c) and is NEVER used for the lineage.
